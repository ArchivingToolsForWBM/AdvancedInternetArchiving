This is a tool that lets you automate visiting URLs in a sequence via opening them in a new tab.

This can be used as an alternative to “sequential URL visit” userscript, and tracking visited URLs to avoid re-visits.

NOTE: Make sure you allow pop-ups here before extracting links, because most browsers disallow javascript from opening multiple tabs at once as an anti-popup-ads/tabs measure.
